# PRD: sonic-tradelytics

> 상태: 초안 · 담당: @소닉 · 최종 수정: 2026-10-27

## 1. 배경과 문제

단타를 직접 하면 장중에 계속 화면을 봐야 하고, 감정적으로 사고팔게 돼요. 자동매매 봇을 써도 대부분 "샀다/팔았다"만 남아서 **왜 샀는지, 예상이 맞았는지**를 알 수 없고, 그래서 규칙을 고쳐도 나아졌는지 판단할 수 없어요.

sonic-tradelytics는 토스증권 오픈API로 내 계좌를 연결하고, 단타 유형별 규칙을 가진 봇이 장중에 스스로 매수·매도해요. 핵심은 **막 사고파는 봇이 아니라, 매 거래마다 근거·예측·결과가 남아 검증 가능한 봇**이에요.

## 2. 목표와 비목표

**목표**

| ID | 목표 |
| --- | --- |
| G1 | 모든 주문에 근거 기록이 100% 남는다 |
| G2 | 봇별 예측 정확도를 기간별로 비교할 수 있다 |
| G3 | 손실 한도와 안전장치가 사람 개입 없이 작동한다 |
| G4 | 새 봇은 소액 상한으로 검증하고, 기준을 넘은 봇만 투자금을 늘린다 |

**비목표** (이번 제품 범위에서 하지 않음)

- 여러 사용자 대상 서비스 (본인 1인 사용)
- 해외 주식, 파생상품
- 수익 보장, 종목 추천
- 사람이 쓴 문장으로 된 모호한 근거 ("좋아 보여서")

## 3. 사용자

| 항목 | 내용 |
| --- | --- |
| 대상 | 본인 계좌로 국내 주식 단타를 자동화하려는 개인 투자자 1인 |
| 사용 환경 | 장중에는 휴대폰으로 상태 확인·긴급 정지, 장 마감 후에는 PC로 실적·근거 분석 |
| 핵심 시나리오 | ① 봇을 만들어 소액 상한으로 2주 이상 돌린다 → ② 실적·정확도를 보고 규칙 값을 조정한다 → ③ 기준을 넘으면 상한을 풀고 투자금을 늘린다 → ④ 이상하면 즉시 멈춘다 |

## 4. 범위

**포함**

- 시장: 국내 주식(코스피·코스닥)
- 봇 유형: 스캘핑, 데이 트레이딩, 스윙, 종가 베팅 (도입 순서는 [로드맵](../project/roadmap.md))
- 검증 구간(투자금 상한)과 상한 해제. 사용자용 모의 모드는 없음 ([Q-018](../project/open-questions.md#q-018))
- 기능 F1~F4와 공통 기능(알림, 킬 스위치)

**이후 버전** (우선순위는 [로드맵 백로그](../project/roadmap.md#백로그))

백테스트, 일일·주간 리포트, 봇 버전별 성과 비교 화면, A/B 비교, 시장 상황 필터, 이벤트 캘린더, AI 해설, 세금·비용 리포트

| ID | 기능 | 요약 | 명세 |

| F2 | 봇별 투자 실적 | 전체 요약 → 봇 비교 → 봇 상세 → 개별 거래로 내려가며 순손익·위험 지표를 본다 | [f2-performance.md](./features/f2-performance.md) |

## 6. 성공 지표

| 지표 | 목표 | 측정 방법 |
| --- | --- | --- |
| 근거 기록 커버리지 | 100% | 체결된 봇 주문 중 근거(decision)와 연결된 비율 |
| 안전장치 위반 | 0건 | 손실 한도·투자금 한도를 넘은 주문 수 |
| 정확도 비교 가능성 | 모든 봇 | 봇별·기간별 방향 적중률이 계산되는 봇 비율 |
| 상한 해제 | 기준 통과 봇만 | 기준([POL-RISK-13](../policy/risk-management.md#9-검증-구간과-상한-해제-pol-risk-13)) 미달 봇의 상한 해제 0건, 검증 구간 봇의 상한 초과 주문 0건 |

## 7. 비기능 요구사항

| ID | 요구사항 |
| --- | --- |
| NFR-01 | **안전 우선**: 시세·잔고·DB 중 하나라도 불확실하면 신규 진입을 멈춘다. 수익 기회를 놓치는 쪽을 택한다 |
| NFR-02 | **긴급 정지 속도**: 킬 스위치를 누르면 1초 안에 신규 주문이 멈춘다 |
| NFR-03 | **호출 한도 준수**: 토스 API 한도를 넘는 호출을 보내지 않는다. 한도가 모자라면 판단을 건너뛰고 기록한다 |
| NFR-04 | **기록 불변**: 근거·주문·체결 기록은 추가만 하고 수정·삭제하지 않는다 (재평가도 새 기록으로 이어 붙임) |
| NFR-05 | **금액 정확성**: 금액은 원 단위 정수로 다룬다. 실전 순손익은 체결 내역의 실제 수수료·세금을 쓴다 |
| NFR-06 | **보안**: API 키는 저장소에 넣지 않고 암호화 저장, 허용 IP 제한. 관리 화면은 외부에 공개하지 않는다 |
| NFR-07 | **가용성**: 장 운영 시간(평일 08:30~15:40) 동안 매매 엔진이 동작한다. 장애 시 알림을 보낸다 |

## 8. 가정과 제약

- 토스증권 오픈API(2026-08-13 정식 출시)로 잔고 조회, 자동 주문, 조건주문, 실시간 시세(웹소켓)가 가능하다. 세부 스펙은 공식 문서로 확인했다 ([연동 문서](../integrations/toss-securities-api.md))
- API로 받은 정보는 본인 매매 목적으로만 쓸 수 있고 제3자 배포는 금지된다 (토스 데이터 이용 정책)
- API 사용을 위해 고정 IP 서버가 필요하다
- 자동매매로 생긴 손실은 투자자 본인에게 귀속된다
- 이 서비스는 특정 전략이나 종목의 수익을 보장하지 않는다
