# F3. 투자 근거 리포트

> 상태: 초안 · 담당: @소닉 · 최종 수정: 2026-10-26 · 상위: [PRD](../prd.md)

## 개요

봇은 주문 직전에 **왜 사는지, 얼마까지 갈 것으로 보는지**를 기록하고, 청산 후 실제 결과를 붙여 예측이 맞았는지 자동 채점해요. 기록이 쌓이면 어떤 규칙이 실제로 잘 맞는지 데이터로 알 수 있어요.

**표현 원칙**: 근거는 규칙과 숫자로만 써요. "좋아 보여서" 같은 모호한 문장은 남기지 않아요.

## 근거 카드 (거래 1건)

| 구분 | 기록 내용 | 예시 |
| --- | --- | --- |
| 판단 시점 | 일시, 봇(버전), 종목, 당시 가격 | 10:12:30, 스캘핑봇A v3, 000000, 12,350원 |
| 충족한 조건 | 통과한 규칙과 그 값 | 거래량 3.4배(기준 3배), 직전 고점 12,300원 돌파 |
| 탈락한 조건 | 기준에 못 미친 항목(있다면) | 매수 잔량 우위 1.1배(기준 1.2배) — 가중치 낮아 진입 |
| 신뢰 점수 | 조건 충족도를 0~100으로 환산 | 78점 |
| 예측 | 방향, 목표가, 손절가, 예상 보유 시간 | 상승, 12,470원(+1%), 12,290원, 3분 이내 |
| 실제 결과 | 청산가, 실제 보유 시간, 보유 중 최고·최저가 | 12,430원, 2분 40초, 고가 12,450원 |
| 채점 | 방향 적중 여부, 목표 도달률, 예측 오차 | 방향 적중, 목표의 67% 도달, 오차 -0.3% |
| 청산 사유 | 익절 / 손절 / 시간 청산 / 장 마감 청산 / 재평가 청산 / 수동 청산 | 시간 청산 |
| 재평가 기록 | 이월 봇만. 재평가마다 수정 예측을 시간순으로 이어 붙임 | [포지션 재평가](../../policy/position-reevaluation.md) |

## 채점 정의

| 항목 | 정의 |
| --- | --- |
| 방향 적중 | 예측 방향과 (청산가 − 진입가)의 부호가 같으면 적중 |
| 목표 도달률 | (보유 중 최고가 − 진입가) ÷ (목표가 − 진입가), 0~100%로 자름 (상승 예측 기준) |
| 예측 오차 | (청산가 − 목표가) ÷ 진입가 |

## 정확도 분석 화면

- 봇별 방향 적중률, 목표가 도달률, 평균 예측 오차
- 신뢰 점수 구간별 실제 승률 (예: 80점 이상이면 승률이 정말 높은지)
- 조건별 기여도: 어떤 조건이 충족됐을 때 수익이 났는지
- 건너뛴 판단: 조건 미달로 진입하지 않은 종목이 이후 어떻게 움직였는지 비교
- 최초 판단 vs 재평가 판단 적중률 (재평가가 실제로 성과를 개선하는지)

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-RAT-01 | 주문 전에 근거 카드(판단 시점·조건·점수·예측)를 저장하고, 저장 실패 시 주문하지 않는다 | Must |
| FR-RAT-02 | 청산 시 실제 결과를 붙이고 자동 채점한다 | Must |
| FR-RAT-03 | 리스크·자금 검사에서 막힌 판단도 사유와 함께 "건너뛴 판단"으로 기록한다 | Must |
| FR-RAT-04 | 종목 필터를 통과했지만 진입 조건에서 떨어진 후보를 기록하고, 장 마감 후 이후 가격을 채운다 | Should |
| FR-RAT-05 | 정확도 분석: 봇별 적중률·도달률·오차, 점수 구간별 승률 | Must |
| FR-RAT-06 | 정확도 분석: 조건별 기여도, 건너뛴 판단 비교, 최초 vs 재평가 비교 | Should |
| FR-RAT-07 | 근거는 규칙 id와 숫자 값으로만 저장한다 (자유 문장 필드 없음) | Must |
