# F2. 봇별 투자 실적

> 상태: 초안 · 담당: @소닉 · 최종 수정: 2026-10-27 · 상위: [PRD](../prd.md)

## 개요

실적 화면은 **전체 요약 → 봇 비교 → 봇 상세 → 개별 거래** 순서로 내려가며 봐요. 수익률만이 아니라 수수료·세금을 뺀 순손익과 위험 지표를 함께 보여줘야 봇의 진짜 실력을 판단할 수 있어요.

## 화면 구성

| 화면 | 내용 |
| --- | --- |
| 홈(전체 요약) | 토스증권 계좌 예수금·평가금액, 오늘 전체 손익, 실행 중인 봇 수, 오늘 거래 건수, 킬 스위치 |
| 봇 비교 | 아래 지표를 봇별로 한 줄씩, 정렬 가능 |
| 봇 상세 | 일별 손익 그래프, 누적 수익 곡선, 기간 필터(일·주·월·전체), 자금 정보 |
| 투자 내역 | 전체 탭 / 봇별 탭 (아래) |

## 봇별 핵심 지표

| 지표 | 정의 | 왜 필요한가 |
| --- | --- | --- |
| 누적·기간 수익률 | 기간 순손익 ÷ 확정 투자금 | 기본 성과 |
| 승률 | 순손익 > 0인 청산 포지션 수 ÷ 청산 포지션 수 | 판단 정확도 감 |
| 손익비 | 평균 순이익 ÷ 평균 순손실(절댓값) | 승률이 낮아도 수익이 나는지 |
| 최대 낙폭(MDD) | 누적 손익 곡선의 고점 대비 최대 하락 폭 | 버틸 수 있는 위험인지 |
| 평균 보유 시간 | 진입~청산 평균 | 유형 의도대로 동작하는지 |
| 거래 비용 합계 | 수수료 + 세금 | 단타는 비용이 수익을 잠식하기 쉬움 |
| 벤치마크 대비 | 같은 기간 코스피·코스닥 수익률과 비교 | 그냥 지수를 산 것보다 나은지 |

순손익은 모두 수수료·세금 차감 후 값이에요 ([NFR-05](../prd.md#7-비기능-요구사항)).

## 투자 내역

같은 내역 화면을 두 탭으로 나눠 계좌 전체 흐름과 봇 하나의 기록을 각각 봐요.

| 탭 | 범위 | 상단 요약 |
| --- | --- | --- |
| 전체 | 모든 봇 + 직접 거래, 최신순, 봇 이름 컬럼 포함 | 기간 내 거래 수, 순손익, 거래 비용, 봇별 손익 비중 |
| 봇별 | 선택한 봇 하나 | 확정 투자금, 사용 중 금액, 남은 한도, 누적 손익, 손실 중지까지 남은 여유 |

**목록 컬럼**

| 컬럼 | 내용 |
| --- | --- |
| 일시 | 진입·청산 시각 |
| 봇 | 봇 이름과 유형 (전체 탭에서만). 직접 거래는 "직접 거래" |
| 종목 | 종목명·코드 |
| 수량·가격 | 매수 평균가, 매도 평균가, 수량 |
| 순손익 | 금액과 % (보유 중이면 평가 손익) |
| 상태 | 보유 중 / 청산 완료 / 미체결 / 취소 |
| 청산 사유 | 익절 / 손절 / 시간 청산 / 장 마감 청산 / 재평가 청산 / 수동 청산 |
| 근거 | 해당 거래의 [근거 카드](./f3-rationale-report.md)로 이동 |

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-PERF-01 | 홈에 계좌 요약과 오늘 손익, 실행 중 봇 수, 거래 건수를 보여준다 | Must |
| FR-PERF-02 | 봇 비교 표에 위 지표를 봇별로 보여주고 정렬할 수 있다 | Must |
| FR-PERF-03 | 봇 상세에 일별 손익, 누적 곡선, 기간 필터를 제공한다 | Must |
| FR-PERF-04 | 거래 1줄 = 진입부터 청산까지 포지션 1개. 펼치면 분할 매수·매도의 개별 주문과 주문별 체결 합계(평균가·수량·수수료·세금)가 보인다 | Must |
| FR-PERF-05 | 필터: 기간, 봇(다중 선택), 종목, 수익/손실, 상태, 청산 사유 | Must |
| FR-PERF-06 | 보유 중 포지션은 맨 위에 고정하고 평가 손익을 실시간 갱신한다 | Should |
| FR-PERF-07 | 직접 거래는 "직접 거래"로 구분 표시한다 ([F4](./f4-manual-trades.md)) | Must |
| FR-PERF-08 | 내역을 CSV로 내려받는다 | Should |
| FR-PERF-09 | 벤치마크(코스피·코스닥) 대비 수익률을 보여준다 | Should |
| FR-PERF-10 | 봇 상세에서 검증 구간과 상한 해제 이후 성과를 나눠 보여준다. 모든 봇이 실제 계좌로 매매하므로 홈의 계좌 손익·전체 손익에는 모두 합산한다 | Must |
