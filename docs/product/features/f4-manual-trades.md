# F4. 직접 거래 추적

> 상태: 초안 · 담당: @소닉 · 최종 수정: 2026-10-26 · 상위: [PRD](../prd.md)

## 개요

토스증권 앱에서 직접 한 거래도 계좌 체결·보유 내역을 가져와 **직접 거래**로 자동 분류하고, 봇과 같은 기준으로 성과를 추적해요. 원하면 직접 거래에도 근거와 예측을 입력해 채점받을 수 있어요.

## 기능

| 기능 | 내용 |
| --- | --- |
| 자동 수집 | 장중 일정 간격 + 장 마감 후 계좌 체결·보유 내역 동기화 |
| 자동 분류 | 봇이 낸 주문의 `orderId`와 대조해, 나머지 주문은 직접 거래로 분류. 토스 주문 조회는 앱·WTS 주문도 포함하지만, 장전·장후 시간외 종가 주문은 조회되지 않아요 |
| 근거 입력(선택) | 매수 이유 메모, 목표가, 손절가, 예상 보유 기간 → 봇과 같은 방식으로 채점 |
| 가격 알림 | 직접 보유 종목이 입력한 목표가·손절가에 닿으면 알림 (자동 매도는 하지 않음) |
| 나 vs 봇 비교 | 수익률, 승률, 손익비, MDD, 예측 적중률을 같은 기간·같은 기준으로 비교 |

## 규칙

- 같은 종목을 봇과 직접 둘 다 보유하면 수량을 나눠 기록해요. 봇 주문으로 체결된 수량만 봇 몫이에요
- 직접 낸 **미체결 주문**이 있는 종목에는 봇이 신규 진입하지 않아요. 봇이 청산하려는데 직접 낸 반대 방향 미체결 주문 때문에 막히면 알림이 와요 ([POL-RISK-16](../../policy/risk-management.md#5-1-종목-잠금-pol-risk-16))
- 직접 보유 주식은 봇 운용 자산 계산에서 제외해요 ([POL-FUND-02](../../policy/fund-allocation.md))
- 직접 거래의 메모는 F3의 "숫자로만" 원칙에서 예외로, 자유 문장을 허용해요. 채점은 목표가·손절가 숫자로만 해요

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-MAN-01 | 계좌 체결을 봇 주문과 대조해 직접 거래를 자동 분류한다 | Must (봇 주문 분리가 자금 계산에 필요) |
| FR-MAN-02 | 같은 종목 혼합 보유 시 수량을 봇 몫/직접 몫으로 나눈다 | Must |
| FR-MAN-03 | 직접 거래에 근거·예측을 입력하고 채점받는다 | Could |
| FR-MAN-04 | 직접 보유 종목 목표가·손절가 도달 알림 | Could |
| FR-MAN-05 | 나 vs 봇 비교 화면 | Could |
| FR-MAN-06 | 서비스 시작 전 과거 주문을 가져온다. 계좌 개설 이후 전체 조회 가능, 단 분할 체결은 주문 단위 합계로만 남음 ([Q-003](../../project/open-questions.md#q-003)) | Could |
