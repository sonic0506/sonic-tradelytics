# F1. 봇 생성 및 세부 설정

> 상태: 초안 · 담당: @소닉 · 최종 수정: 2026-10-29 · 상위: [PRD](../prd.md)

## 개요

봇은 **유형 선택 → 자금·기간 설정 → 규칙 값 조정 → 안전장치 설정** 4단계로 만들어요. 규칙 값은 유형별 기본값을 제공해 숫자만 고치면 바로 시작할 수 있어요.

## 사용자 스토리

- 나는 봇 유형과 투자 성향만 고르고 기본값으로 바로 소액으로 봇을 시작하고 싶다
- 나는 규칙 숫자를 바꿨을 때 이전 버전과 성과를 비교하고 싶다
- 나는 장중 언제든 봇 하나를 멈추거나 전량 청산하고 싶다

## 생성 단계

| 단계 | 입력 | 화면 동작 |
| --- | --- | --- |
| 1. 유형 | 스캘핑 / 데이 트레이딩 / 스윙 / 종가 베팅, 투자 성향(공격적·중립·소극적) | 유형·성향별 기본값 자동 입력. 이월 유형(스윙·종가 베팅)은 갭 하락 위험 안내 |
| 2. 자금·기간 | 투자금(정률/정액), 정액이면 시작 우선순위, 1회 주문 금액, 분할 매수 횟수, 동시 보유 종목 수, 운용 기간, 운영 시간 | 같은 시각 시작 봇들의 정률 합이 100%를 넘으면 저장 불가, 정액 포함 총액이 현재 운용 자산을 넘으면 경고 ([POL-FUND-03](../../policy/fund-allocation.md#기본)) |
| 3. 규칙 값 | 유형별 종목 필터·진입·청산 값 | 기본값 옆에 사용자가 바꾼 값 표시 |
| 4. 안전장치 | 손실 중지 %, 연속 손절 횟수, 하루 한도 도달 시 보유분 처리 | 성향 기본값 자동 입력 ([리스크 관리](../../policy/risk-management.md)) |

## 공통 설정

| 설정 | 선택지 | 비고 |
| --- | --- | --- |
| 봇 유형 | 스캘핑 / 데이 트레이딩 / 스윙 / 종가 베팅 | 유형별 기본 규칙 자동 적용 |
| 운용 기간 | 시작일~종료일, 또는 무기한 | 종료일 도달 시 보유분 처리(청산/유지) 선택 |
| 투자금 | 운용 자산 대비 %(기본) 또는 정액 | 시작 시점에 확정 ([자금 배분](../../policy/fund-allocation.md)). 시작 뒤에는 봇이 쉬는 중(보유 종목·미체결 주문 없음, 운영 시간 밖)일 때만 "투자금 다시 정하기"로 바꿔요 (POL-FUND-12). 검증 구간에는 상한(예: 10만 원)까지만 확정 (POL-FUND-11) |
| 1회 주문 금액 | 투자금 대비 % 또는 정액 | 분할 매수 횟수와 함께 설정 |
| 동시 보유 종목 수 | 1~N개 | 분산 정도 결정 |
| 운영 시간 | 예: 09:05~15:15 | KRX 정규장(09:00~15:30) 안에서만 설정 가능 ([POL-RISK-15](../../policy/risk-management.md#4-1-매매-시간-pol-risk-15)). 장 초반·동시호가 제외 옵션 |
| 단계 | 검증 중 / 상한 해제 | 선택하지 않음. 신규 봇은 검증 중으로 시작하고, 기준을 통과하면 상한 해제 ([POL-RISK-13](../../policy/risk-management.md#9-검증-구간과-상한-해제-pol-risk-13)) |

## 유형별 규칙 (기본값 제공, 사용자는 숫자만 조정)

| 봇 유형 | 종목 필터 | 진입 조건 | 청산 조건 |
| --- | --- | --- | --- |
| 스캘핑 | 거래대금 상위 N위, 주가 범위 | 거래량 급증 배수, 직전 고점 돌파 | 익절 %, 손절 %, 최대 보유 분 |
| 데이 트레이딩 | 거래대금 급증, 시가 대비 상승률 | VWAP 지지 확인 | 분할 익절, VWAP 이탈, 장 마감 전 청산 시각 |
| 스윙 | 이동평균 정배열, 시가총액 하한 | 20일선 근접 + RSI 반등 | 목표가, 20일선 이탈, 최대 보유일 |
| 종가 베팅 | 당일 상승률, 고가 유지 | 마감 직전 시간대·고가 대비 위치 | 다음 날 매도 시각, 갭 하락 시 손절 |

구체적인 기본 숫자는 각 봇 도입 단계([로드맵](../../project/roadmap.md))에서 이 표에 채워요.

### 데이 트레이딩 기본값 (중립, 2026-10-30 확정)

| 구분 | 값 | `bot_versions.params` |
| --- | --- | --- |
| 종목 필터 | 거래대금 실시간 순위 30위 안(투자 유의 종목 제외), 주가 1,000~200,000원, 시가 대비 +2%~+10% | `maxRank` `minPrice` `maxPrice` `minRisePct` `maxRisePct` |
| 진입 | 현재가가 오늘 정규장 VWAP 위 0~1% 안 (VWAP 지지) | `vwapBandPct` |
| 청산 | +2%에 절반, +4%에 나머지 익절. VWAP 아래 0.5% 이탈 시 전량. 15:15 전량 청산 | `takeProfit1Pct` `takeProfit2Pct` `vwapExitPct` `exitAt` |
| 손절 | 진입가 -2% 손절 조건주문 (POL-RISK-11) | `stopLossPct` |
| 재진입 대기 | 청산한 종목은 30분 동안 다시 사지 않아요 (2026-10-30 리플레이에서 같은 종목 반복 진입 손실을 보고 더함) | `reentryCooldownMinutes` |
| 판단 주기 | 10초 | — |

- 진입 조건을 모두 충족해야 진입해요. 근거 카드의 점수는 충족한 조건 비율(0~100)이에요
- 목표가(마지막 익절 단계)·손절가는 호가 단위로 내림해요

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-BOT-01 | 4단계로 봇을 생성하고, 유형·성향 선택 시 기본값을 자동으로 채운다 | Must |
| FR-BOT-02 | 신규 봇은 검증 구간(투자금 상한 적용)으로 시작한다. 모의(가상 투자금) 모드는 없다 | Must |
| FR-BOT-03 | 규칙 값을 바꾸면 새 버전으로 저장하고, 이전 버전 기록은 그대로 둔다 | Must |
| FR-BOT-04 | 봇 단위 일시정지·재개·즉시 전량 청산을 제공한다 | Must |
| FR-BOT-05 | 같은 시각 시작 실전 봇들의 정률 합이 100%를 넘으면 저장·시작을 막는다. 정액을 포함한 예상 배분 결과(확정·보류 예정)를 현재 운용 자산 기준으로 미리 보여준다 | Must |
| FR-BOT-10 | 정액 봇은 시작 우선순위를 정할 수 있다(기본: 생성 순서). 자금이 모자라 보류된 봇은 "자금 부족 대기" 상태와 사유를 보여주고, 금액을 줄여 바로 다시 시작할 수 있다 ([POL-FUND-14, 15](../../policy/fund-allocation.md#정액정률-혼합)) | Must |
| FR-BOT-06 | 상한 해제는 기준(POL-RISK-13)을 통과한 봇만 가능하다. 봇 목록과 상세에 "검증 중" 표시와 상한 금액을 보여주고, 상세에 기준별 현재 값과 통과 여부를 보여준다. 기준을 통과하면 알린다 | Must |
| FR-BOT-07 | 이월 유형(스윙·종가 베팅) 생성 시 밤사이 갭 하락 위험을 안내한다 | Should |
| FR-BOT-08 | 운용 기간 종료 시 설정한 방식(청산/유지)으로 보유분을 처리한다 | Must |
| FR-BOT-09 | 실행 중·일시정지 봇은 쉬는 중일 때 "투자금 다시 정하기"로 투자금을 늘리거나 줄인다. 상한이 풀린 봇의 투자금 확대도 이 기능이다 (POL-FUND-12) | Must |
| FR-BOT-11 | 규칙 값을 저장할 때 판단이 바뀌는 변경이면 "검증 구간부터 다시 시작"을, 위험만 줄이는 변경이면 "검증 기록 유지"를 저장 전에 알려준다. 지금 쉬는 중이라 바로 적용되는지, 쉬는 중이 된 뒤 적용되는지도 함께 알려준다 (POL-RISK-13) | Must |
| FR-BOT-12 | 봇 목록·상세·설정에 오늘 운영 상황(운영 중 · 쉬는 중 · 하루 한도 도달 · 휴장)과 다음 운영 시각을 보여준다. 봇 상태(`status`)는 바꾸지 않고 운영 시간·보유·장 일정으로 계산한다 | Should |

## 수용 기준 (예시)

- 데이 트레이딩·중립을 고르면 손실 중지 값이 하루 -4% · 누적 -10%로 채워진다
- 실행 중 봇의 투자금 필드는 쉬는 중이 아니면 수정할 수 없고, 이유(보유 종목 있음 · 운영 시간 안)를 보여준다
- 쉬는 중인 데이 트레이딩 봇의 규칙 값을 바꿔 저장하면 바로 적용되고, 보유 종목이 있는 스윙 봇은 적용 대기가 된다
- 규칙 값을 바꿔 저장하면 버전 번호가 1 오르고, 이후 판단 기록은 새 버전 id로 남는다
