# 보유 포지션 재평가 정책

> 상태: 초안 · 담당: @소닉 · 최종 수정: 2026-10-26
> 관련: [F3 근거 리포트](../product/features/f3-rationale-report.md) · [자금 배분](./fund-allocation.md) · [리스크 관리](./risk-management.md) · [DART 연동](../integrations/dart-open-api.md)

날짜를 넘겨 보유하는 **스윙·종가 베팅** 봇은 정해진 시각마다 "처음 산 이유가 아직 유효한지"를 다시 판단하고, 유지·조정·청산을 결정해요. 스캘핑·데이 트레이딩은 당일 청산이라 대상이 아니에요.

## 실행 일정

| 시각 | 배치 | 대상 | 확인하는 것 (데이터 출처) | 결과 |
| --- | --- | --- | --- | --- |
| 15:40 장 마감 후 | 장후 재평가 | 스윙, 종가 베팅 | 당일 종가·거래량, 진입 근거 유효성, 추세, 목표·손절가 (토스) | 다음 날 행동 계획 (유지 / 익절 예약 / 손절 예약 / 비중 축소) |
| 08:30 장 시작 전 | 장전 점검 | 스윙, 종가 베팅 | 밤사이 공시 (DART), 미국 대표 ETF 전일 등락률·원/달러 환율 (토스), NXT 거래 종목의 프리마켓 체결가 (토스) | 경계 표시(공시 경계·시장 경계)와 시초가 대응 계획 |
| 09:00~09:05 개장 직후 | 개장 직후 점검 | 스윙, 종가 베팅 | 실제 시초가와 갭 (토스) | 시초가 대응 확정 (갭 상승 시 매도 시각, 갭 하락 시 손절 여부) |
| 11:00, 14:00 장중 | 장중 점검 | 스윙 | 추세 이탈 여부, 거래량 급변 (토스) | 필요 시 조기 청산 |
| 매주 금요일 장후 | 주간 점검 | 스윙 | 보유 기간 대비 진행도 (토스) | 최대 보유일 임박 시 정리 여부 |

- 휴장일에는 배치를 건너뛰고, 장 운영 캘린더 기준 다음 거래일 일정으로 실행해요
- 뉴스는 판단에 쓰지 않아요 ([ADR-0008](../architecture/adr/0008-external-data-numeric-only.md))
- 다음 주 실적 발표 일정은 지금 데이터 출처가 없어 확인하지 않아요. 백로그의 이벤트 캘린더에서 다뤄요

## 장전 점검과 개장 직후 점검 (POL-REEV-06)

국내 조건주문은 KRX 정규장에서만 발동하고, 토스 API에는 예상 체결가가 없어요. 그래서 시초가 대응을 두 단계로 나눠요.

**08:30 장전 점검**: 경계 표시를 정하고 계획을 세워요.

| 신호 | 조건 (기본값, 봇 버전 설정값으로 조정) | 표시 |
| --- | --- | --- |
| 공시 | 보유 종목에 전 거래일 장 마감(15:30) 이후 DART 공시 유형 **주요사항보고(B)** 또는 **거래소공시(I)** 가 있음 | 공시 경계 (그 종목) |
| 미국 증시 | 대표 ETF(SPY, QQQ, SOXX) 중 하나라도 전일 정규장 등락률 −2% 이하 | 시장 경계 (전체) |
| 환율 | 원/달러 환율이 전 거래일 대비 ±1% 이상 변동 | 시장 경계 (전체) |
| NXT 프리마켓 | NXT 거래 종목이고 08:00 이후 체결이 있으면, `(최근 체결가 − 전일 종가) ÷ 전일 종가`를 갭 추정치로 기록 | 갭 추정 (그 종목) |

- 경계 표시가 있으면 그날 해당 이월 봇의 **신규 진입을 멈추고**, 보유분은 개장 직후 점검에서 목표가를 기다리지 않고 청산 여부를 먼저 판단해요
- 공시 내용(호재·악재)은 해석하지 않아요. 공시가 "있다"는 사실과 유형 코드만 써요

**09:00~09:05 개장 직후 점검**: 실제 시초가로 확정해요.

| 상황 | 대응 |
| --- | --- |
| 시초가가 손절가 아래 (갭 하락) | 즉시 청산. 손절 조건주문을 먼저 취소하고 매도해요 ([POL-RISK-14](./risk-management.md#7-1-손절-조건주문과-봇-매도의-순서-pol-risk-14)). 이미 발동했으면 그 체결을 손절로 기록 |
| 시초가가 목표가 위 (갭 상승) | 장후 재평가에서 정한 매도 시각에 맞춰 익절. 공시·시장 경계가 있으면 바로 익절 |
| 그 사이 | 장후 재평가 계획대로. 경계가 있으면 손절가를 올리는 방향으로 조정 검토 (POL-REEV-01) |

## 판단 항목

| 항목 | 내용 | 출처 |
| --- | --- | --- |
| 진입 근거 유효성 | 매수 당시 충족한 조건(예: 20일선 위, 상승 추세)이 지금도 유지되는지 | 토스 시세 |
| 손익 위치 | 현재 수익률이 목표가·손절가 사이 어디에 있는지 | 토스 시세 |
| 시간 진행도 | 예상 보유 기간 대비 경과일. 기간만 가고 움직임이 없으면 정리 후보 | 내부 기록 |
| 이벤트 | 밤사이 공시, 휴장일 전날 여부 | DART, 토스 장 캘린더 |
| 시장 상황 | 국내 지수 급락, 미국 대표 ETF 급락, 환율 급변 시 보수적으로 판단 | 토스 시장 지표·미국 시세·환율 |

## 정책

| ID | 정책 |
| --- | --- |
| POL-REEV-01 | 손절가는 올리는(손실을 줄이는) 방향으로만 수정할 수 있어요. 낮추는 것은 금지 |
| POL-REEV-02 | 재평가로 투자금을 늘리거나 추가 매수 한도를 키울 수 없어요 ([POL-FUND-08](./fund-allocation.md)) |
| POL-REEV-03 | 판단 결과는 근거 카드에 "재평가 기록"으로 시간순으로 이어 붙여요: 최초 예측 → 재평가별 수정 예측 → 실제 결과. 이전 기록은 수정하지 않아요. 경계 표시는 근거 값과 함께 기록해요 (예: "QQQ −2.4% (기준 −2%) → 시장 경계", "공시 B 1건 → 공시 경계") |
| POL-REEV-04 | 최초 판단과 재평가 판단의 적중률을 따로 채점해요. 재평가가 실제로 성과를 개선하는지 검증하기 위함 |
| POL-REEV-05 | 배치가 실패하거나 시세를 못 받으면 해당 봇은 신규 진입 중단 + 알림. 기존 손절 조건 주문은 유지 ([POL-RISK-11](./risk-management.md)) |
| POL-REEV-06 | 시초가 대응은 08:30 장전 점검과 09:00~09:05 개장 직후 점검 두 단계로 해요 (위 절) |
| POL-REEV-07 | 외부 데이터(DART)를 못 받으면 해당 신호는 **경계가 있는 것으로** 보고 진행하고 알려요. 모르면 보수적으로 판단해요 ([NFR-01](../product/prd.md#7-비기능-요구사항)) |

## 갭 하락 위험

스윙·종가 베팅은 시초가가 손절가 아래로 열리면 설정보다 큰 손실이 날 수 있어요. 봇 생성 시 안내하고([FR-BOT-07](../product/features/f1-bot-setup.md)), 장전 점검과 개장 직후 점검으로 대응해요.
