# ADR-0008. 외부 데이터는 숫자·코드로 바꿀 수 있는 공식 API만 판단에 사용

- 상태: 제안
- 날짜: 2026-10-26

## 맥락

이월 봇의 장전 점검은 공시·뉴스·해외 증시·예상 체결가를 봐야 하는데, 토스 API로는 일부만 얻을 수 있어요([Q-017](../../project/open-questions.md#q-017)). 외부 데이터를 붙이면 판단 재료는 늘지만, 원본 기획의 원칙("근거는 규칙과 숫자로만")과 예측 채점을 지키기 어려워질 수 있어요.

## 결정

- 판단 조건에 쓰는 외부 데이터는 **공식 API**로 받고, **숫자나 정해진 코드**로 바꿀 수 있는 것만 써요
- 공시: DART Open API의 공시 유형 코드와 개수만 사용, 내용은 해석하지 않음 ([DART 연동](../../integrations/dart-open-api.md))
- 해외 증시: 새 출처 대신 토스 API의 미국 대표 ETF 시세와 원/달러 환율 사용 ([토스 연동](../../integrations/toss-securities-api.md))
- 예상 체결가: 계산하지 않고 NXT 프리마켓 체결가와 실제 시초가로 대체 ([POL-REEV-06](../../policy/position-reevaluation.md#장전-점검과-개장-직후-점검-pol-reev-06))
- 뉴스·웹 검색·LLM 요약은 **판단 조건에 쓰지 않아요**. 쓰더라도 화면의 참고 정보(백로그 "AI 해설")로만 둬요
- 외부 데이터를 못 받으면 그 신호는 경계가 있는 것으로 봐요 (보수적 기본값)

## 결과

- 모든 판단 근거가 근거 카드에 숫자·코드로 남아 채점과 재현이 가능해요
- 외부 연동은 DART 하나만 늘어요
- 감수: 공시 없는 이슈(업황 뉴스, 루머)는 판단에 들어가지 않아요. 그런 영향은 가격 움직임(갭, 시초가)으로만 반영돼요
- 감수: DART 공시 경계는 내용과 무관하게 걸리므로 호재 공시에도 보수적으로 움직여요. 채점 결과를 보고 유형 세분화를 검토해요

## 검토한 대안

- 뉴스 검색 API로 기사 수를 지표화: 숫자로는 남지만 방향(호재·악재)과 무관해 근거로 약해요
- LLM 웹 검색 요약으로 판단: 결과가 매번 달라 검증·채점이 불가능해요
- 동시호가 호가로 예상 체결가 직접 계산: 토스 문서에 근거가 없어 틀려도 알기 어려워요
