# ADR-0006. 관리 화면은 앱 로그인 대신 네트워크로 접근 제한

- 상태: 제안
- 날짜: 2026-10-26

## 맥락

사용자는 본인 1명이에요. 관리 화면에서 봇을 만들고 실전 주문을 일으킬 수 있어서, 외부에 노출되면 피해가 커요. 장중에는 휴대폰에서도 킬 스위치를 눌러야 해요.

## 결정

- web과 api는 공인 인터넷에 열지 않고 Tailscale(사설망) 안에서만 접근해요
- 앱 안에 회원가입·로그인 기능은 만들지 않아요
- 서버 방화벽은 SSH와 Tailscale만 허용해요

## 결과

- 인증 코드를 만들고 지키는 부담이 없어요
- 휴대폰에 Tailscale 앱만 깔면 어디서든 접근돼요
- 감수: 다른 사람에게 보여주려면 별도 방법이 필요해요. 그때 Cloudflare Access 같은 앞단 인증을 검토해요

## 검토한 대안

- 앱 자체 로그인(비밀번호 + 2FA): 만들고 관리할 코드가 늘고, 실수하면 그대로 노출돼요
- Cloudflare Access: 좋은 대안이지만 도메인 설정이 필요해요. 공개가 필요해질 때 다시 검토
