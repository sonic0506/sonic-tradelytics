# 용어집

> 상태: 초안 · 담당: @소닉 · 최종 수정: 2026-10-27

문서와 코드에서 같은 말을 같은 뜻으로 써요. 코드 이름은 오른쪽 열을 따라요.

## 자금

| 용어 | 뜻 | 코드 이름 |
| --- | --- | --- |
| 운용 자산 | 새 봇에 배분할 수 있는 돈. 주문 가능 금액 − 실행 중인 실전 봇들의 현금 몫. 직접 보유 주식 제외 | `availableCapital` |
| 스냅샷 | 배분 기준으로 찍어 둔 계좌 금액 기록 | `AccountSnapshot` |
| 확정 투자금 | 봇 시작 시 운용 자산 × 비율로 정해진, 운용 중 불변인 금액 | `fixedBudget` |
| 사용 중 금액 | 보유 종목 매수 금액 + 미체결 매수 주문 금액 | `usedAmount` |
| 남은 한도 | 확정 투자금 − 사용 중 금액 | `remainingBudget` |
| 미배분 | 어떤 봇에도 배분되지 않은 운용 자산 | `unallocated` |
| 반환 | 봇 종료·중지 시 남은 금액이 운용 자산으로 돌아가는 것 | `release` |
| 이월 봇 | 날짜를 넘겨 보유하는 봇 (스윙, 종가 베팅) | `carryOver` |
| 정률 / 정액 | 투자금 설정 방식. 운용 자산 대비 비율 / 금액 | `BudgetType`: `ratio` / `fixed` |
| 현금 몫 | 실전 봇에 묶였지만 아직 현금으로 남은 돈. 확정 투자금 + 실현 손익 − 보유 매수 금액 − 미체결 매수 금액 | `cashShare` |
| 시작 우선순위 | 같은 시각 정액 봇들이 남은 돈을 받는 순서 | `startPriority` |
| 자금 부족 대기 | 설정 금액을 확정할 돈이 모자라 시작이 보류된 상태 | `BotStatus.waiting_funds` |

## 봇과 판단

| 용어 | 뜻 | 코드 이름 |
| --- | --- | --- |
| 봇 유형 | 스캘핑 / 데이 트레이딩 / 스윙 / 종가 베팅 | `BotType`: `scalping` / `day` / `swing` / `closing` |
| 투자 성향 | 공격적 / 중립 / 소극적. 손실 한도·주문 비중 기본값을 정함 | `RiskProfile`: `aggressive` / `neutral` / `conservative` |
| 봇 단계 | 검증 중(투자금 상한 적용) / 상한 해제. 모의 모드는 없음 | `BotStage`: `verifying` / `released` |
| 검증 구간 | 새 봇이나 판단이 바뀐 새 버전이 상한 해제 기준(POL-RISK-13)을 채우는 기간 | `BotStage.verifying` |
| 봇 버전 | 규칙 값이 바뀔 때마다 새로 만드는 설정 묶음 | `BotVersion` |
| 판단 | 봇이 한 시점에 한 종목에 대해 내린 결정 (진입·청산·건너뜀·재평가) | `Decision` |
| 근거 카드 | 판단 하나의 충족·탈락 조건, 점수, 예측, 결과, 채점을 모은 화면 | — |
| 신뢰 점수 | 조건 충족도를 0~100으로 환산한 값 | `score` |
| 예측 | 방향, 목표가, 손절가, 예상 보유 시간 | `Prediction` |
| 건너뛴 판단 | 조건 미달이나 리스크·자금 검사로 주문하지 않은 판단 | `Decision(kind=skip)` |
| 재평가 | 이월 봇이 보유 이유가 아직 유효한지 다시 판단하는 것 | `Decision(kind=reeval)` |
| 장전 점검 / 개장 직후 점검 | 이월 봇의 08:30 경계 판단 / 09:00~09:05 실제 시초가로 갭 대응 확정 | `PreOpenCheck` / `OpeningCheck` |
| 공시 경계 / 시장 경계 | 장전 점검에서 공시(DART 유형 B·I) / 미국 ETF 급락·환율 급변이 있을 때 붙는 표시. 그날 신규 진입을 멈추고 보수적으로 판단 | `DisclosureAlert` / `MarketAlert` |
| 포지션 | 진입부터 청산까지 한 종목 보유 1건. 거래 목록의 한 줄 | `Position` |
| 청산 사유 | 익절 / 손절 / 시간 청산 / 장 마감 청산 / 재평가 청산 / 수동 청산 | `ExitReason` |
| 직접 거래 | 봇이 아닌 사용자가 토스 앱에서 직접 한 거래 | `Position(botId=null)` |

## 지표

| 용어 | 뜻 |
| --- | --- |
| 순손익 | 수수료·세금을 뺀 손익 |
| 승률 | 순손익 > 0인 청산 포지션 수 ÷ 청산 포지션 수 |
| 손익비 | 평균 순이익 ÷ 평균 순손실(절댓값) |
| MDD | 누적 손익 곡선의 고점 대비 최대 하락 폭 |
| 방향 적중 | 예측 방향과 실제 손익 부호가 같음 |
| 목표 도달률 | 보유 중 최고가가 목표까지 간 비율 |

## 시장·증권

| 용어 | 뜻 |
| --- | --- |
| VWAP | 거래량 가중 평균 가격 |
| VI | 변동성 완화장치. 발동 중에는 단일가 매매로 전환됨 |
| 동시호가 | 장 시작 전·마감 직전 주문을 모아 한 가격에 체결하는 시간대 |
| 갭 하락 | 시초가가 전일 종가보다 크게 낮게 시작하는 것 |
| D+2 | 매도 대금이 실제 예수금으로 들어오는 결제일 (매도일 + 2영업일) |
| clientOrderId | 주문 중복 방지 ID(최대 36자, 10분 유효). 이 서비스에서는 판단 id(UUID)와 같음 |
| orderId | 토스가 주문 접수 시 발급하는 주문 식별자. 봇 주문/직접 거래 구분에 사용 |
| accountSeq | 토스 계좌 식별 번호. `X-Tossinvest-Account` 헤더 값 |
| 조건 주문 | 지정한 가격 조건에 도달하면 증권사가 자동으로 내는 주문 |
| SINGLE / OCO / OTO | 조건주문 타입. 조건 1개 / 매도 조건 2개 중 하나 발동 시 나머지 취소 / 매수 체결 후 매도 감시 시작 |
| NXT | 넥스트레이드(대체거래소). 토스 API 국내 시세·주문은 KRX + NXT 통합 |
| 정규장 | KRX 09:00~15:30. 국내 조건주문은 이 시간에만 발동 |
| 킬 스위치 | 모든 봇을 즉시 멈추고 미체결 주문을 취소하는 비상 정지 |
| DART | 금융감독원 전자공시시스템. Open API로 공시 목록을 제공 |
