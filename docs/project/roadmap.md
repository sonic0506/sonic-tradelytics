# 로드맵

> 상태: 초안 · 담당: @소닉 · 최종 수정: 2026-10-29
> 관련: [PRD](../product/prd.md) · [미결정 사항](./open-questions.md) · [리스크](./risks.md)

한 번에 4개 봇을 다 만들기보다 **잔고 연동과 근거 기록 구조를 먼저 완성하고 봇은 하나씩 늘려요**. 안전장치는 수익 로직보다 먼저 만들어요. 기간은 1인 기준 예상치예요.

## 의존 관계

```
M0 ─▶ M1 ─▶ M2 ─▶ M3 ─┬─▶ M5 (M3 점검 통과 필요)
                      └─▶ M4 (M3와 병행 가능)
            M2 ─▶ M6 ─▶ M7
```

M3를 개발 PC에서 돌리는 동안은 이렇게 챙겨요. 장중(08:30~15:40)에 PC가 잠들거나 꺼지지 않게 하고, 공유기 공인 IP가 바뀌면 토스가 `ip-not-allowed`(403)로 막으니 허용 IP를 다시 등록해요. "5거래일 연속 무중단"은 엔진 버그로 멈추지 않는 것을 보는 기준이라, PC를 꺼서 멈춘 날은 세지 않고 다시 세요.

M3 점검을 통과하면 바로 M5로 소액 실전을 시작할 수 있어요. 검증 구간 10거래일이 지나는 동안 M4·M6를 만들어요.

## 백로그

원본 기획의 추가 추천 기능과 Could 요구사항이에요. M7에서 위에서부터 꺼내요.

| 순위 | 기능 | 설명 | 원본 우선순위 |
| --- | --- | --- | --- |
| 1 | 직접 거래 추적 (F4 Could) | 근거 입력, 가격 알림, 나 vs 봇 비교 | — |
| 2 | 일일·주간 리포트 | 장 마감 후 봇별 손익, 잘한·못한 거래 요약, 규칙 조정 제안 | 중간 |
| 3 | 백테스트 | 과거 시세로 규칙 검증 (학습·검증 기간 분리). 규칙이 순수 함수라 재사용 가능. 국내 1분봉은 2022-11-23 이후 제공 | 높음 |
| 4 | 봇 버전별 성과 비교 화면 | 버전 저장은 M2에서 이미 함. 비교 화면만 추가 | 중간 |
| 5 | A/B 비교 | 같은 유형에 숫자만 다른 봇 2개를 검증 구간 상한으로 동시 운영 | 중간 |
| 6 | 시장 상황 필터 | 지수 급락·고변동성 날 신규 진입 중단 | 중간 |
| 7 | 전체 자금 관리 | 봇 합산 투자금·보유 비중 상한 (같은 종목 중복 방지는 종목 잠금 POL-RISK-16으로 M2에 앞당김) | 중간 |
| 8 | 스캘핑 봇 | 웹소켓 실시간 체결이 확인돼 기술적 전제는 충족(Q-001). 데이 트레이딩 실전 안정화 후 착수 | — |

원본에서 "높음"이던 실시간 알림·킬 스위치는 MVP(M1~M3)에 넣었어요. 모의투자는 사용자 기능으로는 빼고 개발 점검(M3)과 소액 검증 구간(M5)으로 나눴어요([Q-018](./open-questions.md#q-018)). 백테스트는 "높음"이지만 검증 구간이 먼저 같은 역할을 하므로 M7로 뒀어요.
